# homepage

A personal, mobile-first browser start page. It is a static website with no build step.

## Use

Open `index.html` in a browser, or serve this folder with a static file server. Weather and location work best when served over HTTPS (GitHub Pages does this automatically).

## Personalize

- Choose a wallpaper image.
- Add and edit favourite links. Website icons load from the selected icon source; each link can also have its own icon URL.
- Choose a widget style and set three custom RGB colours in **Personalize**.
- Set weather by city, or allow browser location access.
- Search suggestions are generated locally; submitting a search opens Google.

Preferences are saved in the current browser's local storage and do not sync between devices.

## Publish with GitHub Pages

Push the files to a GitHub repository. In repository settings, enable **Pages** and select the `main` branch and `/ (root)` as the source. The current local branch is `master`; rename it to `main` or choose `master` in the Pages settings.
